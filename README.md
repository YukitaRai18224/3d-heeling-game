# 🌾 포근 농장 (Cozy Farm)

브라우저에서 바로 즐기는 3D 힐링 농장 게임이에요. [Three.js](https://threejs.org/)로 만들었고, 설치나 빌드 과정 없이 실행돼요.

## 즐길 거리

- **밭 가꾸기** — 땅 갈기 → 씨앗 심기 → 물 주기 → 수확. 밭을 클릭하면 그때 필요한 일을 알아서 해요.
- **작물 4종** — 🥕 당근, 🍅 토마토, 🌻 해바라기, 🎃 호박. 단계마다 물을 줘야 다음 단계로 자라요.
- **상점** — 수확해서 번 돈으로 씨앗을 사고 닭을 입양할 수 있어요.
- **닭** 🐔 — 쓰다듬으면 하트가 나오고, 아침마다 달걀을 낳아요.
- **하루의 흐름** — 실제 6분이 게임 속 하루예요. 아침노을, 저녁노을, 반딧불이가 나는 밤이 있어요.
- **날씨** — 가끔 비가 오는데, 비가 오면 작물이 저절로 물을 머금어요.
- **잔잔한 음악** — Web Audio로 직접 만들어 내는 배경음악과 빗소리가 나와요.
- **자동 저장** — 진행 상황은 브라우저(localStorage)에 저장돼요.

## 조작법

| 동작 | 키 |
| --- | --- |
| 이동 | WASD / 방향키, 또는 땅 클릭(터치) |
| 밭 / 닭 / 달걀과 상호작용 | 클릭(터치), 또는 가까이에서 스페이스바 |
| 씨앗 고르기 | 1 ~ 4, 또는 아래 칸 클릭 |
| 카메라 회전 | Q / E |
| 확대 · 축소 | 마우스 휠 |

## 실행하기

ES 모듈을 쓰기 때문에 파일을 더블클릭하지 말고, 작은 로컬 서버로 열어 주세요.

```bash
python3 -m http.server 8123
```

그다음 브라우저에서 http://localhost:8123 을 열면 돼요.

GitHub Pages를 켜면(Settings → Pages → `main` 브랜치) 웹에서 바로 플레이할 수도 있어요.

## 파일 구성

- `index.html` — 화면 구성과 UI
- `style.css` — UI 스타일
- `main.js` — 3D 월드, 게임 로직, 사운드 전부
